# CAS Continuing Education Tracker

A mobile app that helps CAS professionals track, manage, and report continuing education (CE) credits from courses, conferences, webinars, certifications, and other learning activities.

## Overview

Continuing Education Tracker simplifies the process of recording educational activities and monitoring progress toward the annual credit requirements.

This app is currently in development.

## Features

### Credit Tracking
- Log CE activities in seconds
- Track earned credits by category
- View total credits accumulated
- Monitor progress toward requirements

### Activity Management
- Easily edit/update CE
- Store completion dates
- Add notes and supporting details


### Progress Dashboard
- Visual progress indicators by CE Type

### Reporting (Future State)
- Generate and email an Excel spreadsheet in the template provided by CAS for auditing

## Technology Stack

### Mobile
- Ionic Angular

### Backend
- .NET Web API
- SQL Server

## Installation
